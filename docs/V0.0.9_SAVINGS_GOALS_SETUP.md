# Finzaro V0.0.9 — Savings Goals Setup

## 1. Chạy SQL trên Supabase

Vào **Supabase → SQL Editor → New query**, mở file:

```text
supabase/sql-editor/V0.0.9_savings_goals.sql
```

Copy toàn bộ nội dung và bấm **Run**.

Không cần chạy lại SQL của V0.0.3 → V0.0.7 nếu database hiện tại đã có các version đó.

## 2. Kiểm tra schema

Có thể chạy file read-only:

```text
supabase/sql-editor/V0.0.9_savings_goals_verify.sql
```

Sau khi migration thành công sẽ có:

```text
savings_goals
savings_goal_entries
```

và RLS cho từng user.

## 3. Ý nghĩa dữ liệu

Savings Goal là lớp lập kế hoạch/earmarking. Việc ghi nhận `contribution`, `withdrawal` hay `adjustment` **không tự thay đổi số dư Account**.

Muốn số dư thật thay đổi, hãy tạo Income/Expense/Transfer trong Transaction Core. Sau đó có thể chọn Transaction phù hợp trong form Goal Progress để tạo trace giữa mục tiêu và ledger.

Một Transaction chỉ được liên kết với một Savings Goal Entry để tránh tính cùng một giao dịch nhiều lần.

## 4. Account liên kết

- Account liên kết phải cùng currency với Goal.
- Account đã archive không thể gắn vào Goal đang hoạt động.
- Goal không khóa hay giữ riêng số dư của Account.
- Có thể dùng một Account cho nhiều Goal; progress vẫn được quản lý độc lập bằng `savings_goal_entries`.

## 5. ENV

V0.0.9 không cần ENV mới. Tiếp tục sử dụng:

```env
NEXT_PUBLIC_FINZARO_ENV=development
NEXT_PUBLIC_SITE_URL=https://your-finzaro.vercel.app
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxx
```

## 6. Test sau deploy

1. Mở `/goals`.
2. Tạo Goal 100.000.000 VND với target date.
3. Ghi nhận đóng góp 10.000.000 VND.
4. Kiểm tra progress = 10%.
5. Ghi nhận withdrawal 2.000.000 VND.
6. Kiểm tra saved còn 8.000.000 VND.
7. Tạo Transfer thật vào Account tiết kiệm, sau đó liên kết Transaction đó với một contribution mới.
8. Kiểm tra Dashboard hiển thị Savings Goals summary.
