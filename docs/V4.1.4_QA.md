# Finzaro V4.1.4 — Financial Accuracy QA

## Unit fixture / independent expectations

Run `npm test`. The dedicated suite `tests/v414-financial-accuracy.test.mjs` creates independent transactions with:

- Multiple expense categories (>5), two income categories, two accounts, uncategorized expenses.
- A transfer, an excluded loan-payment transaction, a different currency, and a prior-period transaction.
- Expected **Thu 250, Chi 140, Ròng 110** in minor units. Top-5 totals are strictly below total expense; bar proportions use the full total.
- Account and category sums by Thu/Chi separately must agree with totals.
- All / Thu / Chi exports must contain only the selected flow types and correct split totals.
- Reconciliation must fail when KPI or monthly totals are deliberately corrupted.
- Day, account, descendant category, type and currency filters must narrow the same source rows.
- Period snapshot checks verify KPI, category slices, bucket sums and counts; altered numbers must fail.
- Invalid dates such as February 30 must be rejected.
