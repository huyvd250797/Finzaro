# Finzaro V1.0.2 — Next.js Security Patch

V1.0.2 is a production security/deploy patch on top of V1.0.1. It does not add finance features and does not change the database schema.

## Changes

- `next`: `16.0.0` → `16.4.0`
- `eslint-config-next`: `16.0.0` → `16.4.0`
- React / React DOM remain aligned at `19.3.0`.
- Vercel install no longer uses `--legacy-peer-deps`.

## Deploy

1. Replace V1.0.1 source with V1.0.2.
2. Commit and push the source.
3. In Vercel, redeploy with **Clear build cache** for the first V1.0.2 deployment.
4. Confirm the install log resolves `next@16.4.0`.
5. Smoke-test authentication, Transactions, Reports, Calendar and PWA install/update.

No Supabase migration is required.
