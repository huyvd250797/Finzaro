# Finzaro V1.1.7 — Reports UI & Calendar Polish

V1.1.7 is a focused Reports visual-density patch on top of the stable V1.1.6 RSC fix.

## Changes

- Compacts the Reports header/navigation and merges month/year selection with the period navigator so the Overview reaches financial data faster.
- Keeps Expense / Income / Net in one compact row on mobile and desktop.
- Pie slices now use each Category's configured `icon_color`; Reports no longer invents a separate chart palette for live category data.
- The pie remains a full solid circle with no center overlay. Large slices show their label and percentage, and tapping a slice shows category, percentage and amount.
- The category legend is a compact two-column, scroll-bounded grid using the same Category icon/color as the rest of Finzaro.
- Calendar no longer forces a 700px canvas on phones. Seven days fit the viewport like a native finance calendar.
- Calendar day cells show green `+Thu` and red `-Chi` on separate lines, omit zero values and omit the currency suffix inside cells to preserve readable exact amounts.
- Calendar Income / Expense / Net cards stay in one row at all breakpoints.

## Database

No migration is required for V1.1.7. Keep the V1.1.2 migration applied for Account → Deposit → Goal transaction integrity.
