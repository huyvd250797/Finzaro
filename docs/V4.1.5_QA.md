# V4.1.5 — Lint/Deploy Regression QA

## Vercel log đầu vào

`eslint .` dừng ở 57 errors / 15 warnings. Nguồn gốc: TypeScript `any` trong dynamic adapters; React Hooks `purity`, `set-state-in-effect`, `refs`; rule Next.js áp nhầm test fixtures; và các cảnh báo dùng biến.

## QA thực hiện tại môi trường đóng gói

- Test regression: `node --test tests/*.test.mjs`.
- Kiểm tra version, release scope và imports: `node scripts/check-release.mjs`.
- Kiểm tra cú pháp: `node --check eslint.config.mjs`; TypeScript transpile syntax check.
- Đối chiếu toàn bộ SQL và nghiệp vụ với ZIP V4.1.4 gốc; không có migration mới.

**Giới hạn quan trọng:** Môi trường đóng gói không cài được npm dependencies từ registry. Các kết quả source tests không đồng nghĩa với lint/typecheck/build thực sự đạt trên Vercel. Kiểm tra CI staging là điều kiện trước production. Sau khi lint pass, có thể phát sinh typecheck/build chưa thấy trong log cũ (do pipeline dừng ở lỗi đầu tiên).
