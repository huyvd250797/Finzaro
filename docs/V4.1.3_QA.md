# Finzaro V4.1.3 — QA / TypeScript Deploy Hotfix

## Kiểm tra được
- `mode` có type `CategoryDrilldownMode` (`month | year`).
- `args` dùng TypeScript `satisfies` đối chiếu chữ ký hàm tổng hợp tại điểm tạo.
- Đã tái hiện đúng TS2345 tại cả hai vị trí khi cố tình bỏ annotation trong bản kiểm thử độc lập; sau sửa, hai lỗi không còn trong kiểm thử độc lập.
- Giữ API auth, RPC V4.1.2, đường fallback và cache headers.
- Giữ nguyên SQL và 6 module.

## Cần kiểm tra trước production
- `npm install` hoặc quy trình cài dependency hợp lệ của dự án.
- `npm run typecheck` và `npm run build` trên Vercel/CI.
- Staging Supabase RPC `report_period_summary_v412`, Tháng/Năm/kỳ trước-kỳ sau, Thu/Chi, modal danh mục.
- Nếu có lỗi TS khác do Vercel báo, phải xử lý lỗi mới thay vì dùng `ignoreBuildErrors`.
