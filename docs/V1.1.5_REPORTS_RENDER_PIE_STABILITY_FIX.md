# Finzaro V1.1.5 — Reports Render & Pie Stability Fix

V1.1.5 addresses the remaining Reports crash after V1.1.4 confirmed that data-loader failures were no longer the only failure mode.

## Root regression

A direct diff against V1.0.2 showed that the interactive pie renderer introduced in V1.1.0 changed from a stable CSS conic-gradient implementation to a custom client-side SVG path renderer. The loader was changed repeatedly in V1.1.1–V1.1.4, but this visualization regression remained untouched.

## Fix

- The pie is again rendered with CSS `conic-gradient` rather than generated SVG paths.
- Users can still tap a colored region directly; pointer angle maps to the corresponding category.
- Large slices continue to show category and percentage labels.
- A client error boundary contains visualization failures locally.
- Money formatting, timezone handling and transaction entry reads are defensive against malformed legacy values.

## Database

No V1.1.5 migration is required. Keep the V1.1.2 migration applied for Account → Deposit funding and Goal contribution/rollback.
