# Finzaro V1.1.9 — Category Grid & Save Performance Fix

V1.1.9 focuses on faster everyday entry and a denser category experience without changing financial accounting rules.

## Category UX

- Income/expense category selection is now a visual 3-column mobile / 4-column larger grid.
- Every block uses the category's configured icon and color.
- A normal tap selects a category.
- Hold for about 360 ms, then drag across blocks to reorder. The order is persisted through the existing `categories.sort_order` field.
- Category Management uses the same compact block language and supports hold/drag ordering.
- The unexplained high-contrast Transactions shortcut on Category Management was removed.

## Save performance

- Create-transaction validation queries for category, accounts, currencies, Deposit and Goal are started in one parallel batch instead of a sequential query waterfall.
- Edit-transaction validation loads transaction, category, account and currency metadata in parallel.
- Cache invalidation after a new transaction is scoped to the modules actually affected instead of invalidating every financial module for every standard income/expense save.

No database migration is required because `categories.sort_order` and update permissions already exist in the Category Engine schema.
