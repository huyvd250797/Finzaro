# Finzaro V0.0.11 — Loan & Debt Manager Setup

## 1. Database migration

Vào **Supabase → SQL Editor → New query**, copy toàn bộ nội dung file:

```text
supabase/sql-editor/V0.0.11_loan_debt_manager.sql
```

và bấm **Run**.

Migration này:

- thêm `icon_color` cho `categories`, `savings_goals`, `deposits`;
- tạo `loans`;
- tạo `loan_payments`;
- hỗ trợ tần suất thanh toán monthly / biweekly / weekly;
- bật RLS theo user;
- kiểm tra currency của linked account;
- chặn principal đã trả vượt quá gốc vay;
- kiểm tra Transaction được link phải là dòng tiền đi ra đúng currency/account;
- chặn archive Account đang được Loan active sử dụng.

Không cần chạy lại SQL V0.0.10 hoặc các migration cũ nếu database đã ở V0.0.10.

## 2. Verify

Có thể chạy file read-only:

```text
supabase/sql-editor/V0.0.11_loan_debt_manager_verify.sql
```

Kiểm tra `loans`, `loan_payments`, `icon_color` và các RLS policy đã tồn tại.

## 3. Không cần ENV mới

V0.0.11 tiếp tục dùng:

```env
NEXT_PUBLIC_FINZARO_ENV=development
NEXT_PUBLIC_SITE_URL=https://your-finzaro.vercel.app
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxx
```

## 4. Test sau deploy

1. Mở `/loans` và tạo khoản vay.
2. Kiểm tra lịch trả nợ dự kiến.
3. Ghi nhận một payment tách Principal / Interest / Fee.
4. Kiểm tra dư nợ giảm đúng theo phần Principal.
5. Thử Loan Simulator với khoản trả thêm mỗi tháng.
6. Kiểm tra Dashboard có Loan summary.
7. Trên iPhone PWA, bấm **Thêm** ở góc phải taskbar và kiểm tra Bottom Sheet.
8. Mở Category / Savings Goal / Deposit / Loan và thử chọn icon + màu.

## 5. PWA mobile UX

V0.0.11 đặt viewport `maximumScale=1`, `userScalable=false`, chặn gesture pinch trong standalone PWA, khóa overflow ngang và chuẩn hóa form control mobile ở 16px để iOS không tự zoom khi focus input.

Nếu icon Home Screen cũ vẫn còn sau deploy, iOS có thể đang cache Apple Touch Icon. Xóa icon Finzaro khỏi Home Screen và Add to Home Screen lại **một lần** để nhận logo mới; không cần đăng nhập bằng Safari trước.
