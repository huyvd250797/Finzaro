# Finzaro V3.2.1 — Deploy Hotfix QA

## Context

Bản V3.2.0 SQL FIX được deploy lên Vercel xuất hiện TypeScript errors:

- `app/(dashboard)/reports/page.tsx(66,17)` — TS2352: `Object.fromEntries` suy ra index signature, thiếu `income`/`expense` trong `Record`.
- `features/transactions/actions.ts(209,22)` — TS18046: không thể đọc `.data` trên `result` kiểu `unknown`.

## Changes

1. Tạo dữ liệu và đường dẫn của hai flow theo khóa tường minh, đảm bảo hợp lệ với `Record<ReportFlowType,...>` mà không ép kiểu không an toàn.
2. Kiểm tra response envelope và mảng receipt trước khi dùng; ngăn RPC trả về ngày trùng hoặc không thuộc yêu cầu.
3. Vẫn sử dụng batch RPC V3.2.0, SQL migration sửa cú pháp `v_expected_entries` không bị chỉnh lại.
4. Tăng app version thành `3.2.1`, giữ nguyên 6 module.

## Local QA results

- `node --test tests/*.test.mjs`: **123/123 PASS**, bao gồm 3 tests mới cho bản vá.
- `node scripts/check-release.mjs`: **PASS**; version v3.2.1, 6 module, import nội bộ hợp lệ.
- `npm install --offline`: **không thực hiện được** vì thiếu bản cache `@supabase/ssr`.
- `npm run typecheck`, `npm run build`: **chưa được xác nhận** trong môi trường này vì không có dependency đầy đủ.

## Deployment gate

Trên CI/Vercel có npm registry, chạy: `npm install && npm run typecheck && npm run test && npm run build`. Sau đó thử chuyển tab Thu/Chi không reload, sao chép 1 ngày và 10 ngày, thử lại cùng ngày để bảo đảm không ghi trùng. Không cần migration mới nếu SQL FIX V3.2.0 đã được cài đặt.
