# Finzaro V0.0.12 — Credit Card Manager Setup

## 1. Database
Trong Supabase **SQL Editor**, chạy duy nhất:

`supabase/sql-editor/V0.0.12_credit_card_manager.sql`

Script tạo `credit_cards`, `credit_card_statements`, `credit_card_payments`, RLS, validation/ledger guards và RPC `update_financial_transaction_v012` để sửa Income/Expense an toàn.

Có thể chạy file read-only `supabase/sql-editor/V0.0.12_credit_card_manager_verify.sql` để kiểm tra sau migration.

## 2. Không cần ENV mới
V0.0.12 dùng lại `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_FINZARO_ENV`.

## 3. Credit Card Manager
- Tạo/sửa/lưu trữ thẻ.
- Hạn mức, dư nợ hiện tại, utilization, lãi suất năm.
- Ngày chốt sao kê + số ngày tới hạn.
- Minimum payment theo % và mức sàn.
- Tạo statement snapshot.
- Ghi nhận payment, tùy chọn link Transaction Ledger.
- Payment tự giảm `current_balance_minor`; xóa payment hoàn lại dư nợ.
- Không lưu full card number/CVV.

## 4. Sửa Thu/Chi
Trang Transactions có nút sửa cho Income/Expense. RPC V0.0.12 hoàn nguyên ledger cũ, cập nhật dữ liệu, tạo ledger entry mới và tính lại Account Balance trong một PostgreSQL transaction. Transfer vẫn không sửa trực tiếp. Transaction đã liên kết Goal/Deposit/Loan/Recurring/Credit Card Payment bị khóa sửa để giữ tính toàn vẹn.

## 5. Danh mục
Category card có nút **Sửa** mở instant modal để cập nhật tên, parent, icon và màu.

## 6. PWA / Mobile UX
- Bottom taskbar đồng nhất icon + label 10px.
- Nút cuối `... Thêm` mở module sheet, có Credit Card Manager và Giao dịch mới.
- Splash loading khi app mount và route loading fallback.
- Viewport tiếp tục khóa zoom; overflow ngang/input mobile vẫn được bảo vệ.
- Visual system mới dùng neutral finance palette, typography system/SF Pro, field/button/card tokens thống nhất.

## 7. Deploy
1. Run SQL V0.0.12.
2. Push source GitHub.
3. Vercel redeploy.
4. Mở PWA và chọn **Cập nhật ngay** khi update prompt xuất hiện.
