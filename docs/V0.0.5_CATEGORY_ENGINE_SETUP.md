# Finzaro V0.0.5 — Category Engine Setup

## 1. Điều kiện trước khi nâng cấp

Project Supabase DEV phải đã chạy các release trước:

- V0.1.1 Foundation
- V0.0.3 Account Core
- V0.0.4 Transaction Core

Không chạy lại các SQL cũ nếu chúng đã được áp dụng.

## 2. Chạy SQL bằng Supabase SQL Editor

Vào:

```text
Supabase Dashboard → SQL Editor → New query
```

Copy toàn bộ nội dung file:

```text
supabase/sql-editor/V0.0.5_category_engine.sql
```

Paste → **Run**.

Script sẽ:

- Tạo `public.categories`.
- Bật RLS theo `user_id`.
- Tạo category thu nhập/chi tiêu mặc định cho user hiện tại.
- Cập nhật `handle_new_user()` để user mới có default categories.
- Thêm `transactions.category_id`.
- Giữ `category_label` làm snapshot lịch sử.
- Chuyển các category text V0.0.4 sang category có cấu trúc.
- Tạo RPC `create_financial_transaction_v005` và `delete_financial_transaction_v005`.
- Thu hồi execute của RPC ghi dữ liệu V0.0.4.

Có thể chạy file read-only sau để kiểm tra:

```text
supabase/sql-editor/V0.0.5_category_engine_verify.sql
```

## 3. Kiểm tra trên app

Sau deploy:

```text
/categories
```

Kiểm tra:

1. Có nhóm Chi tiêu và Thu nhập mặc định.
2. Tạo category mới.
3. Chọn icon.
4. Tạo subcategory dưới category cha cùng loại.
5. Sửa tên/icon.
6. Lưu trữ và khôi phục.
7. Vào `/transactions?new=expense` và xác nhận category picker hiển thị category/icon mới.
8. Tạo giao dịch và kiểm tra icon xuất hiện trong transaction history + dashboard.

## 4. PWA update prompt

V0.0.5 thêm hai lớp phát hiện update:

```text
/api/version
+ Service Worker update lifecycle
```

Khi app đang chạy phiên bản cũ và server/service worker có release mới, Finzaro hiển thị banner:

```text
Có phiên bản Finzaro mới
[Cập nhật ngay]
```

Nút **Cập nhật ngay** sẽ:

1. Yêu cầu service worker kiểm tra update.
2. Activate worker đang chờ bằng `SKIP_WAITING` nếu có.
3. Reload app để nhận Next.js build mới nhất.

`/sw.js` có header `Cache-Control: no-store` và registration dùng `updateViaCache: "none"`.

Navigation HTML vẫn network-only để không cache dashboard authenticated.

### Lưu ý khi chuyển từ V0.0.4 → V0.0.5

V0.0.4 chưa có UI cảnh báo update, nên trên iPhone đã Add to Home Screen có thể cần đóng/mở lại PWA hoặc refresh một lần để nạp code V0.0.5. Từ V0.0.5 trở đi, update prompt sẽ được app tự kiểm tra khi mở lại/foreground và định kỳ khi app đang online.
