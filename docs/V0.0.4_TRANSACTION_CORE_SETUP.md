# Finzaro V0.0.4 — Transaction Core Setup

This release assumes V0.0.2 Authentication and V0.0.3 Account Core are already working.

## 1. Run one SQL file

Open:

```text
Supabase → SQL Editor → New query
```

Copy all content from:

```text
supabase/sql-editor/V0.0.4_transaction_core.sql
```

Paste it into SQL Editor and click **Run**.

Do not rerun the foundation or Account Core SQL.

## 2. What the script changes

It creates:

```text
transactions
transaction_entries
```

and two controlled write functions:

```text
create_financial_transaction_v004(...)
delete_financial_transaction_v004(...)
```

It also hardens `accounts` so a normal authenticated Data API request can no longer directly change:

```text
currency_code
opening_balance_minor
current_balance_minor
```

or hard-delete an account.

Account name/type/institution/archive state remain editable.

## 3. Existing account balances become the baseline

At migration time:

```text
opening_balance_minor := current_balance_minor
```

for any pre-V0.0.4 row where the two differ.

That makes the balance visible immediately before the first ledger transaction the canonical starting balance.

## 6. Functional test

Login and create two active accounts first.

Open:

```text
/transactions
```

### Income

Create an Income into one account. Confirm:

- transaction appears in history;
- account balance increases;
- Dashboard Income increases;
- Dashboard Net Cash Flow increases.

### Expense

Create an Expense. Confirm:

- source account balance decreases;
- Dashboard Expense increases;
- category chart receives the category.

### Transfer

Transfer between two accounts. Confirm:

- source decreases;
- destination increases;
- Dashboard Income and Expense are unchanged.

### Delete/reversal

Delete a transaction from history. Confirm the related account balance is reversed automatically.

## 7. Cross-currency transfer

For same-currency transfers, destination amount can be blank.

For different currencies, provide the actual amount received in the destination currency. Finzaro deliberately does not guess exchange rates in this release.

## 8. RLS / isolation test

Create a second Supabase user. It must not be able to read the first user's rows from:

```text
transactions
transaction_entries
accounts
```

Direct client writes to `transactions` or `transaction_entries` should fail because the authenticated role only has SELECT on those tables.

## 9. Important behavior change from V0.0.3

Do not expect the Account edit form to change balances anymore.

Use:

```text
Income
Expense
Transfer
```

to change current balances. This is intentional and keeps account totals reconcilable with the ledger.
