# Finzaro V2.0.0 — UI/UX acceptance checklist

## Accounts & Wallets

- [ ] Search by name/institution/currency finds the correct account without a network fetch per keystroke.
- [ ] Filter All/Bank/Cash/E-wallet and sort Name/Balance work on mobile and desktop.
- [ ] Each account card shows the original correct balance and correct currency, including long negative figures.
- [ ] Tap history and verify `/transactions?account=<id>` filter; edit/archive/restore keep account balances intact.
- [ ] Legacy savings accounts stay read-only and excluded from normal balance total.

## Categories

- [ ] Search by category name and parent; removing search restores all active categories.
- [ ] Press and hold then drag across tiles; release saves correct order; vertical page scrolling remains usable.
- [ ] Use arrow controls with keyboard and touch; disabled actions do not reorder outside edges.
- [ ] Simulate a write failure: feedback appears, UI refreshes to the actual server order.
- [ ] Archived view shows only archived entries and can restore them. Original icon colors appear in Reports.

## Speed, interaction, accessibility

- [ ] Mobile navigation and + button are not clipped on iPhone safe-area; forms stay usable with keyboard open.
- [ ] `V2.0.0` is visible on the header of a narrow iPhone, in mobile More, desktop sidebar, Settings and `/api/version`.
- [ ] A form modal focuses the first input, traps Tab, closes via Escape and restores focus to the trigger.
- [ ] User with reduced-motion setting sees no unnecessary slide/hover animations.
- [ ] Pinch-to-zoom works in iOS installed PWA; navigation remains usable.
- [ ] PWA updates without caching authenticated HTML; stale service worker can be refreshed using update prompt.

## Data integrity and release gate

- [ ] Before and after totals for each active account agree with ledger, except deliberate new transactions.
- [ ] Create one normal Income, Expense and Transfer; verify target/source balances and that Transfer does not enter Income/Expense reports.
- [ ] Calendar, category pie, drill-down, Export CSV and historic financial entries remain correct.
- [ ] No 13 retired finance routes/modules visible; bookmarked old links redirect safely.
- [ ] `npm run release:check`, `lint`, `typecheck`, `test`, `build` pass with dependencies and production-like env.
