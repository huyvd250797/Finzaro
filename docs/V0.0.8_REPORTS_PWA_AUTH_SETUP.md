# Finzaro V0.0.8 — Reports & Financial Insights + PWA Auth Bootstrap

## 1. Database
V0.0.8 không thêm bảng mới và không yêu cầu chạy migration SQL mới. Reports đọc trực tiếp dữ liệu hiện có từ:
- accounts
- transactions / transaction_entries
- categories
- budgets
- recurring_rules / recurring_occurrences

## 2. PWA trên iPhone
V0.0.8 sửa flow cài Home Screen:

1. Manifest `start_url` chuyển từ `/overview` sang `/pwa?source=homescreen`.
2. `/pwa` là route bootstrap công khai:
   - có session của chính PWA -> `/overview`
   - chưa có session -> `/login?source=pwa`
3. `requireUser()` và auth proxy chịu lỗi an toàn khi chưa có cookie/session.
4. Service worker không cache HTML đăng nhập.
5. Nếu navigation nhận HTTP 5xx, PWA hiển thị `/pwa-error` thay vì màn hình lỗi WebKit/Next.js chung.

### Lưu ý cho PWA đã cài từ bản cũ
Một số phiên bản iOS có thể giữ start URL cũ của shortcut. V0.0.8 vẫn xử lý được trường hợp đó: nếu shortcut mở thẳng `/overview` nhưng PWA chưa có session, dashboard guard sẽ redirect an toàn về `/login`.

Sau khi deploy V0.0.8:
- mở PWA;
- nếu có cảnh báo phiên bản mới, chọn **Cập nhật ngay**;
- đóng hẳn PWA khỏi App Switcher rồi mở lại một lần;
- đăng xuất để kiểm thử: mở lại PWA phải hiện Login ngay trong app.

Nếu iOS vẫn giữ bundle rất cũ từ trước V0.0.5, có thể xóa icon Home Screen và Add to Home Screen lại một lần để nhận manifest mới. Từ V0.0.5 trở đi Finzaro đã có update prompt chủ động.

## 3. Reports
Trang `/reports` hỗ trợ:
- Tháng này / tháng trước / 3 / 6 / 12 tháng / YTD / custom range
- Currency
- Account
- Category (category cha bao gồm subcategory)
- Transaction type
- Income / Expense / Net Cash Flow / Average Expense
- Cash Flow Trend
- Spending by Category
- Spending by Account
- Budget vs Actual
- Recurring Commitments trong 30 ngày
- Rule-based Financial Insights
- CSV export qua `/api/reports/export`

## 4. Deploy
Không cần ENV mới. Giữ nguyên:
- NEXT_PUBLIC_FINZARO_ENV
- NEXT_PUBLIC_SITE_URL
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

Push GitHub -> Vercel redeploy -> cập nhật PWA.
