# Finzaro V0.3.0 — Forecasting & Scenario Planning

## 1. Database

Run in Supabase SQL Editor:

`supabase/sql-editor/V0.3.0_forecasting_scenarios.sql`

This creates `forecast_scenarios` so named scenarios can be reused across devices for the authenticated user. RLS is enabled and every policy is scoped by `auth.uid()`.

Optional verification:

`supabase/sql-editor/V0.3.0_forecasting_scenarios_verify.sql`

## 2. Forecast engine

The baseline forecast is derived from live Finzaro data:

- Account liquid balance
- historical Income / Expense
- active recurring rules
- Loan amortization schedules
- open Credit Card statements
- non-auto-renew Deposit maturities
- current Net Worth context

Transfer transactions are ignored for aggregate cash flow because they move money between the user's own accounts.

No FX conversion is guessed. The engine runs in the default currency selected in Settings.

## 3. Scenario controls

Users can simulate:

- Income percentage change
- Expense percentage change
- Additional monthly income
- Additional monthly spending
- Additional monthly debt repayment
- Monthly savings reserve
- 30 / 90 / 180 / 365 day horizons

Scenario changes do not create Transactions or modify account balances.

## 4. Mobile transaction UI fixes

V0.3.0 replaces the horizontal quick-suggestion carousel with a responsive 2-column mobile grid to prevent clipped cards and broken amounts.

The transaction date field now uses a Finzaro-styled date shell with an invisible native date input overlay. iOS still gets the native date picker, while the visible field stays inside the modal and matches the app UI.

## 5. Deploy

No new environment variables are required. After the SQL migration:

1. Push source to GitHub.
2. Deploy/redeploy on Vercel.
3. Open the installed PWA and use the update prompt.
4. Test `/forecast` and transaction quick entry on iPhone.
