# Finzaro V0.0.10 — Interest & Deposit Manager

## 1. Mục tiêu

V0.0.10 bổ sung lớp quản lý tiền gửi có kỳ hạn trên dữ liệu Supabase thật. Module này theo dõi principal, lãi suất năm, kỳ hạn, ngày gửi/đáo hạn, phương thức nhận lãi, auto-renew, tài khoản liên kết và lãi/thuế/phí thực nhận.

> Deposit Manager là lớp planning/monitoring. Nó không tự thay đổi `accounts.current_balance_minor`. Khi tiền thực sự di chuyển, hãy tạo Transaction trong Transaction Core.

## 2. SQL cần chạy

Trong **Supabase → SQL Editor → New query**, copy toàn bộ file:

```text
supabase/sql-editor/V0.0.10_interest_deposit_manager.sql
```

và bấm **Run**.

Không chạy lại migration cũ nếu database hiện tại đã có V0.0.9.

Có thể kiểm tra read-only bằng:

```text
supabase/sql-editor/V0.0.10_interest_deposit_manager_verify.sql
```

## 3. Bảng mới

- `deposits`: khoản tiền gửi của user.
- `deposit_interest_entries`: lãi thực nhận, thuế, phí hoặc điều chỉnh thực tế.

Cả hai bảng bật RLS và chỉ cho user thao tác dữ liệu của chính mình.

## 4. Cách tính lãi dự kiến

V0.0.10 hỗ trợ:

- `simple_maturity`: lãi đơn theo `principal × annual rate × term/12`.
- `compound_monthly`: lãi kép theo tháng.
- `monthly_payout`: tổng lãi nominal theo lãi đơn, được mô tả là trả lãi hàng tháng.

Kết quả là mô phỏng planning. Ngân hàng thực tế có thể tính theo số ngày, quy ước năm, lãi rút trước hạn, thuế/phí và quy tắc làm tròn riêng.

## 5. Tài khoản liên kết

Nếu chọn linked account:

- currency phải trùng với deposit;
- account không được archived;
- account đang có active deposit sẽ không archive được cho tới khi deposit được archive hoặc gỡ liên kết.

## 6. PWA / Vercel

V0.0.10 không cần ENV mới. Giữ nguyên:

```env
NEXT_PUBLIC_FINZARO_ENV=development
NEXT_PUBLIC_SITE_URL=https://your-finzaro.vercel.app
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxx
```

Sau khi chạy SQL: push GitHub → Vercel redeploy. PWA Update Prompt sẽ phát hiện V0.0.10.
