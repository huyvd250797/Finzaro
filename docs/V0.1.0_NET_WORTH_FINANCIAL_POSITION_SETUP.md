# Finzaro V0.1.0 — Net Worth & Financial Position Setup

## 1. Vì sao là V0.1.0 thay vì V0.0.13?

Theo version policy mới, Net Worth & Financial Position là một module chức năng mới nên tăng `Y`: `0.0.12 → 0.1.0`. Các bản chỉ sửa bug/UI tiếp theo sẽ là `0.1.1`, `0.1.2`...

## 2. SQL Editor

Mở Supabase → SQL Editor → New query, copy toàn bộ:

`supabase/sql-editor/V0.1.0_net_worth_financial_position.sql`

và Run một lần trên Finzaro DEV/Production tương ứng.

File read-only để kiểm tra:

`supabase/sql-editor/V0.1.0_net_worth_financial_position_verify.sql`

Migration tạo `net_worth_snapshots`, RLS/index, đồng thời:

- mở rộng constraint icon Category cho bộ icon mới;
- bảo đảm user vẫn chỉ sửa category của chính mình qua RLS;
- khi user xác nhận đổi tên category đã dùng, `transactions.category_label` được đồng bộ để export/fallback hiển thị tên mới.

## 3. Net Worth calculation

Theo từng currency, Finzaro tính:

`Assets = Account balances + active Deposit principal`

`Liabilities = remaining Loan principal + Credit Card current balance`

`Net Worth = Assets - Liabilities`

Savings Goals không được cộng riêng vào Assets vì Goal là planning/progress layer và có thể đại diện cho tiền đã nằm trong Account; cộng thêm sẽ gây double-count.

Projected deposit interest chỉ hiển thị tham khảo và chưa cộng vào current Net Worth.

Finzaro không tự quy đổi FX. Mỗi currency được xem độc lập để tránh số liệu tài sản ròng sai do tỷ giá không xác định.

## 4. Category metadata confirmation

Category đã có giao dịch vẫn được phép đổi:

- tên;
- icon;
- màu icon;
- parent category hợp lệ.

Nếu category đang được giao dịch sử dụng, app hiện confirm dialog trước khi lưu. Khi xác nhận, giao dịch cũ sẽ hiển thị metadata category mới nhưng amount/ledger/account balance không bị thay đổi.

## 5. Mobile/PWA UX

- Tabbar: `Tổng quan | Giao dịch | (+) | Lịch | Thêm`.
- Nút `(+)` ở giữa mở quick-add giao dịch.
- `Thêm` mở module bottom sheet.
- Modal/bottom sheet lock document; chỉ vùng overlay đang mở được scroll.
- Splash theme script chạy trước paint để splash dùng đúng Light/Dark mode đã lưu, tránh flash Light trước khi chuyển Dark.

## 6. ENV

Không có ENV mới. Tiếp tục dùng:

- `NEXT_PUBLIC_FINZARO_ENV`
- `NEXT_PUBLIC_SITE_URL`
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

## 7. Deploy

1. Run SQL V0.1.0.
2. Push source lên GitHub.
3. Vercel deploy.
4. Mở PWA và chọn `Cập nhật ngay` nếu update prompt xuất hiện.
5. Test `/net-worth`, category edit confirm, center `+`, bottom sheet scroll lock và splash Light/Dark.
