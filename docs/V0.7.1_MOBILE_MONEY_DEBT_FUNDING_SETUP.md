# Finzaro V0.7.1 — Mobile Money UX + Debt Funding

## Upgrade order

1. Ensure the project/database is already on Finzaro V0.7.0.
2. In Supabase SQL Editor, run `supabase/sql-editor/V0.7.1_mobile_money_debt_funding.sql`.
3. Optionally run `supabase/sql-editor/V0.7.1_mobile_money_debt_funding_verify.sql`.
4. Redeploy the V0.7.1 source to Vercel.

## What the migration changes

- Extends `transactions.transaction_purpose` with `credit_card_borrow` and `loan_borrow`.
- Adds `liability_funding_events` so a debt-funded cash inflow can be rolled back safely.
- Adds `create_financial_transaction_v071` for atomic account/liability updates.
- Adds `delete_financial_transaction_v071` for rollback-aware deletion.

## Functional smoke test

1. Add an Income transaction and choose **Lấy tiền từ thẻ tín dụng**. The receiving account should increase by the amount and the selected card debt should increase by the same amount.
2. Add an Income transaction and choose **Giải ngân khoản vay mới**. The receiving account should increase and a new Loan should appear with the entered rate/term/payment configuration.
3. Confirm those two transactions do not inflate the dashboard's real Income total.
4. Open several money fields on iPhone/PWA; the calculator should slide from the bottom and close on **Xong**.
5. Open a form/bottom sheet and scroll; the mobile taskbar should remain pinned to the viewport bottom and form controls should not overflow horizontally.
6. Enter a percentage using `8,5`; it should be normalized and accepted as `8.5`.
