# Finzaro V3.2.0 — QA / Performance Acceptance

## Tự động

- Test regression: `npm run test`.
- Kiểm tra phát hành: `npm run release:check`.
- TypeScript/ESLint/build: `npm run lint && npm run typecheck && npm run build` khi có npm dependencies.
- Test mới trong `tests/v320-instant-performance.test.mjs`: tab Thu/Chi, đồng bộ kỳ, overlay Copy, batch RPC, SQL quyền truy cập và idempotency, splash, cú pháp TS/TSX và hành vi server action với Supabase mock.

## Lưu ý

- Kiểm tra cả các giao dịch khác tiền tệ và chuyển tiền hai tài khoản; chuyển khoản không được cộng vào tổng Thu/Chi.
- Không diễn giải kết quả đo bằng JS mock hoặc phép tính trong bộ nhớ thành latency mạng/RPC thực tế.
- Sau thao tác Copy, mở Báo cáo/kỳ tương ứng và kiểm tra số tiền theo danh mục, tài khoản và số dư.
- Cần đối chiếu trên mobile thao tác vuốt lịch, pinch zoom, focus trap/Escape, chạm một tay, Dark Mode và Reduced Motion.
