# Finzaro V1.1.4 — Reports Recovery & PWA Refresh Fix

V1.1.4 addresses the repeated Reports failure and the observed stale installed-PWA runtime.

## Reports recovery

Reports now use three read strategies in order:

1. Direct date-bounded `transactions` + chunked `transaction_entries` reads.
2. The canonical Transaction Ledger loader already used by the Transactions screen.
3. A V0.0.4-compatible legacy-core reader using only the oldest stable transaction columns and a user-owned entries scan.

Optional Account, Category and Currency metadata remains best-effort. If every read strategy fails, Reports return an empty recoverable result instead of throwing the authenticated dashboard into the route error boundary. Exact database errors remain in Vercel Runtime Logs.

All Reports routes are explicitly `force-dynamic` with `revalidate = 0` to prevent stale authenticated RSC output.

## Installed PWA recovery

The screenshot reported against V1.1.3 still showed `V1.1.2` in both the header and the old V1.1.2 error copy. V1.1.4 therefore adds a one-time hard refresh whenever `/api/version` reports a newer server version than the running client bundle. Finzaro clears its own static cache namespace before reloading with a version cache-buster.

## Database

No V1.1.4 migration is required. Keep V1.1.2 applied for Account → Deposit funding and optional Goal contributions.
