# Finzaro V1.0.1 — Production Deploy Fix

V1.0.1 is a deployment-only patch on top of V1.0.0. It does not add finance features and does not change the database schema.

## Root cause

The V1.0.0 package pinned React and React DOM at 19.2.0 without a committed npm lockfile. On Vercel, npm could enter peer-resolution backtracking against the current React 19.3 line and spend enough time resolving dependencies to hit the platform build timeout.

## Fix

- `react` = `19.3.0`
- `react-dom` = `19.3.0`
- `@types/react` = `19.3.0`
- `@types/react-dom` = `19.3.0`
- `typescript` = `5.9.3`
- Node runtime = `22.x`
- npm runtime = `10.x`
- Vercel install command uses `--legacy-peer-deps --no-audit --no-fund --prefer-offline` to prevent peer solver backtracking and avoid non-build network work.

The direct React packages are intentionally aligned before enabling legacy peer handling, so this flag is not being used to conceal the reported React/React DOM mismatch.

## Database

No migration is required. Continue using the V1.0.0 production verification script if a database health check is desired.

## Deploy

1. Replace the V1.0.0 source with V1.0.1.
2. Push to GitHub.
3. In Vercel, redeploy with **Clear build cache** once, because the failed V1.0.0 dependency tree may be cached.
4. Confirm the install phase no longer reports React 19.2/19.3 peer override warnings.
5. Confirm `next build` begins promptly after dependency installation.
