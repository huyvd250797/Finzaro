# Finzaro V1.1.8 — Calendar Interaction & Performance Fix

V1.1.8 is a focused mobile Calendar UX/performance patch on top of V1.1.7.

## Calendar interaction

- The month ledger loads once; selecting another day is local client state and does not trigger a new server request.
- Double-tap/double-click a date opens the quick-entry chooser for Expense, Income or Transfer.
- The selected date is passed to the transaction form and prefilled.
- Successful create/edit/delete returns to `/reports/calendar` with the original month/day and `#calendar-day-detail`.
- Selected-day rows support horizontal swipe to reveal Edit/Delete. Transfer rows stay non-editable by design to protect double-entry integrity.

## Calendar readability

- Day cells are taller.
- Day-cell amounts round to whole major currency units and never render decimal fractions.
- Income stays green, expense stays red and zero values stay hidden.

## Performance

- Day changes no longer call Supabase.
- Transaction routes are prefetched from the calendar.
- Calendar-originated edit routes load a smaller day-scoped ledger window; calendar-originated quick-create routes use a reduced recent-ledger window.

No database migration is required.
