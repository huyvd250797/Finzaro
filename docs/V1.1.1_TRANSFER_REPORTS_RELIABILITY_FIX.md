# Finzaro V1.1.1 — Transfer & Reports Reliability Fix

## Scope

V1.1.1 is a patch release. It does not add a new finance module or database schema. It fixes two regressions reported after V1.1.0.

## Transfer → Savings → Goal

- Destination accounts are grouped so **Tài khoản tiết kiệm** appears separately and before normal accounts.
- Active Savings accounts also appear as horizontal quick-select buttons on mobile.
- After a Savings destination is selected, **Thêm vào mục tiêu** is shown.
- If that Savings account already has a linked active Goal, only that Goal is offered to avoid updating two Goals from one transfer.
- If the Savings account has no linked Goal, same-currency unlinked active Goals are available for selection.
- The atomic `create_transfer_with_goal_v110` RPC from V1.1.0 remains the write path.

## Reports reliability

The report-specific hydration loader introduced in V1.1.0 was replaced internally with the already production-tested Transaction Ledger loader using full-range pagination. This restores the same canonical transaction/category/account hydration behavior used before V1.1.0 while preserving the new V1.1.0 Reports UI.
