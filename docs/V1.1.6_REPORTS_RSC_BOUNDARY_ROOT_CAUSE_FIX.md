# Finzaro V1.1.6 — Reports RSC Boundary Root Cause Fix

## Confirmed root cause

`app/(dashboard)/reports/page.tsx` is a React Server Component. V1.1.5 imported both `ReportDonut` and `reportSliceColor` from `components/report-donut.tsx`. That module starts with `"use client"`. Rendering a Client Component from a Server Component is valid, but executing a function exported by that client module on the server is not.

The crash occurred while rendering category ranking progress colors:

```tsx
backgroundColor: reportSliceColor(index)
```

Because that call happens in the Server Component, `ReportVisualBoundary` around the pie could never catch it. The error therefore escalated to `app/(dashboard)/reports/error.tsx`. It also only appeared when category data existed, which is why static/empty-state checks did not expose it.

## Fix

- Added `features/reports/palette.ts` with no `"use client"` directive and no React/browser dependencies.
- Both `/reports/page.tsx` and `components/report-donut.tsx` import `reportSliceColor` from that shared server-safe module.
- The Client Component exports only the interactive `ReportDonut` component/type, not executable helpers used by the server.
- Added a regression test that scans Reports Server Components and rejects lower-case executable imports from client modules.

## Database

No V1.1.6 migration is required. Keep the V1.1.2 migration applied for Account → Deposit → Goal funding/rollback.
