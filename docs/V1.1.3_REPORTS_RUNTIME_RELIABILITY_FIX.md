# Finzaro V1.1.3 — Reports Runtime Reliability Fix

V1.1.3 removes the versioned Reports RPC from the mandatory runtime path after V1.1.2 still failed on some deployed Supabase schemas.

## Runtime strategy

Reports now loads the stable ledger core directly:

1. date-bounded `transactions` pages;
2. chunked `transaction_entries`;
3. optional Categories / Accounts / Currencies metadata as best-effort decoration.

No embedded PostgREST relation and no report RPC is required for Overview, Calendar, Category Detail or Analysis. If optional metadata is unavailable, Reports still renders amounts and transaction snapshots instead of failing the whole route.

## Database

No V1.1.3 migration is required. Keep the V1.1.2 migration applied for Account → Deposit funding and optional Goal contributions.

## Smoke test

- Open Reports Overview for current month and year.
- Open Calendar and select a day with both Income and Expense.
- Open a Category detail view.
- Open Analysis.
- Confirm missing/legacy metadata does not blank the Reports module.
