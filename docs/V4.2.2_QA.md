## Chạy kiểm chứng

- `npm run check` trên CI/Vercel; kiểm tra không còn TS18046.
- `npm run test` và `node scripts/check-release.mjs`.
- QA trên staging cùng Supabase: mở Dashboard, Báo cáo, chuyển Tháng/Năm, chọn danh mục/cột, xuất file đối chiếu tổng số tiền, logout/login và PWA.

## Phân biệt mức độ kiểm chứng

Bộ test TypeScript strict này sử dụng fixture độc lập nhằm chứng minh việc narrowing `unknown` là hợp lệ. Nó **không thay thế** typecheck của cả dự án có đầy đủ dependency; production build vẫn chỉ có thể xác nhận từ CI/Vercel trong môi trường hiện tại. Tốc độ và truy vấn SQL thực tế cũng cần xác nhận tại Supabase staging.
