# Finzaro V0.8.0 — Release Candidate

V0.8.0 is the release-candidate build before V1.0.0. The feature set remains frozen at the product-module level; this release focuses on report usability, navigation clarity, validation consistency and deploy readiness using the financial data already present in Finzaro.

## Reports UX consolidation

- `/reports` becomes the default monthly/yearly overview.
- `/reports/calendar` shows real Income and Expense directly inside each calendar day.
- Calendar rules: Income uses green, Expense uses red, and zero-value lines are hidden.
- `/reports/analysis` preserves the existing advanced filters, cash-flow trend, budget comparison, recurring commitments and rule-based insights.
- `/reports/category/[categoryId]` provides monthly/yearly category drill-down with trend bars and transaction history.
- Standard income is the only income counted in analytics; Loan/Credit Card funding remains excluded from real income.
- Mobile navigation promotes Reports while Recurring remains available from the module sheet.

## Category icon expansion

- Category picker expands to 84 supported Lucide icons.
- Added search by Vietnamese label or Lucide icon name.
- Added icons for medicine, hotels, utilities, art, delivery, pets, food, travel, charity, electricity and other common personal-finance use cases.
- Database allow-list is upgraded in the V0.8.0 migration so every icon available in the UI can be persisted safely.

## Database upgrade

After V0.7.5, run:

`supabase/sql-editor/V0.8.0_release_candidate.sql`

Optional verification:

`supabase/sql-editor/V0.8.0_release_candidate_verify.sql`

The migration only replaces the Category icon CHECK constraint. It does not rewrite transaction amounts, balances or ledger history.

## Release checks

Run in a dependency-complete environment:

1. `npm run lint`
2. `npm run typecheck`
3. `npm run test`
4. `npm run build`

V0.8.0 is intended to be the final candidate line before V1.0.0 production release.
