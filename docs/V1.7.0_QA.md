# V1.7.0 QA — evidence and release limitations

## Checked in source environment

- `npm test`: 65/65 **pass** on the active six-module suite. Historical obsolete tests are retained under `tests/legacy/` and not presented as active product coverage.
- `npm run release:check`: **pass** — validates application/package versions, patched runtime version alignment, six active dashboard modules, unchanged constrained transaction RPCs, internal imports, and RSC client-module boundaries.
- Global TypeScript transpile scan: **95 TS/TSX files**, zero parse/transpile diagnostics.
- Local application import resolution: **238 import edges** resolved.
- Source ZIP: verified after packaging. Build artifacts excluded.

## Not verified in this environment

- `npm install`: npm registry fetches timed out. No local dependency tree is available.
- `npm run typecheck`: cannot complete a meaningful semantic check because Next/React/Supabase module declarations are absent. The raw output contains missing-import and JSX type errors; this is NOT a passed type-check.
- `npm run lint` and `npm run build`: require packages; not confirmed. Run with real credentials in a CI/preview environment prior to promoting to production.
- No direct connection was made to the user's Supabase project, so financial correctness against their real transactions and performance metrics are **not measured**.

## Required production acceptance

- CI: env check → release check → eslint → strict tsc → node tests → Next production build.
- Preview iPhone/PWA: calendar selected day instant, double-tap and swipe; after save redirects to same day; larger grid and colored +/- amounts; taskbar Add fully visible.
- Reports: month/year, category-colored pie (entire ring visible), tap each segment and legend, category detail path.
- Overview: balances and three summary KPIs match V1.4.1 for the same period. Verify legacy records remain excluded from ordinary income/expense.
