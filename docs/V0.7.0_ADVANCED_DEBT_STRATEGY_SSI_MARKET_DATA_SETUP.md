# Finzaro V0.7.0 — Advanced Debt Strategy + SSI Market Data

## 1. Supabase
Run only:

`supabase/sql-editor/V0.7.0_advanced_debt_strategy_ssi_market_data.sql`

Then optionally verify with:

`supabase/sql-editor/V0.7.0_advanced_debt_strategy_ssi_market_data_verify.sql`

Do not rerun older migrations if the database is already on V0.6.0.

## 2. SSI FastConnect (optional)
Manual asset valuation continues to work without SSI credentials. To enable automatic Vietnam stock quotes, create/register a FastConnect API key in SSI Developer Portal and configure these **server-only** Vercel environment variables:

```env
SSI_FASTCONNECT_API_KEY=...
SSI_FASTCONNECT_API_SECRET=...
SSI_FASTCONNECT_CLIENT_ID=...
```

`SSI_FASTCONNECT_CLIENT_ID` is optional for market-data-only usage in Finzaro, but can be supplied if SSI assigns one.

Never prefix these values with `NEXT_PUBLIC_` and never commit them to GitHub.

V0.7.0 uses SSI Market Data current Securities Summary with periodic server-side refresh. It does not place orders and does not need OTP. SSI WebSocket push streaming requires an authenticated streaming session/OTP according to current SSI documentation, so Finzaro keeps credentials server-side and uses a Vercel-friendly refresh flow rather than exposing trading/stream credentials to the browser.

## 3. Price units and P/L
Finzaro stores stock purchase price and market price as VND/share. Vietnam market quotations are commonly displayed in units of 1,000 VND (for example `19.05` represents `19,050 VND`). The SSI adapter normalizes such quote values to VND/share before calculating market value and unrealized gain/loss. Values already returned in full VND are left unchanged.

Example: 1,000 SSI shares at an average buy price of 17,500 VND and a normalized market price of 19,050 VND produce a market value of 19,050,000 VND and unrealized P/L of +1,550,000 VND.
