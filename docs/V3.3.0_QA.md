# Finzaro V3.3.0 — QA & Release Evidence

## Tình trạng

- Baseline: source ZIP V3.2.1 do người dùng gửi; không sửa migration hoặc logic hạch toán.
- Giao diện: Light/Dark semantic tokens, primitives, header, sidebar, mobile tabbar, sheet, auth, Overview và Report KPI.
- Tự động: `npm test`: **128/128 đạt**; `node scripts/check-release.mjs`: PASS, 6 module / 119 file source / 300 local imports; TypeScript isolated transpile syntax: **119/119 không lỗi cú pháp**; PostCSS parse: PASS; kiểm tra checksum: **24/24 migration SQL không đổi**.
- Chưa xác nhận: ESLint, TypeScript semantic typecheck, Next production build, browser screenshot/UAT thật, live Supabase. Cần xác nhận trong CI/Vercel trước khi production.

## Kiểm thử hồi quy khi deploy

| Khu vực | Kịch bản | Kỳ vọng |
|---|---|---|
| Light/Dark | Đổi theme từ header; refresh | Không chớp nền sai theme, token phù hợp |
| Tổng quan | Có/không có số dư, số tiền rất dài | Card chính dễ đọc, không tràn |
| Thu/Chi/Chuyển | Mở, điền, hủy, lưu | Không thay đổi nghiệp vụ, focus hợp lệ |
| Copy | Mở sheet, chọn nhiều ngày, xác nhận, thử lại | Không nhân đôi, scroll ổn, RPC hoạt động |
| Danh mục | Tìm, chọn, cuộn > 4 dòng | Vẫn hoạt động và không làm dài form |
| Lịch | Chọn ngày/chi tiết, cuộn trong sheet | Thao tác vuốt không kẹt |
| Báo cáo | Chuyển Thu/Chi, chọn kỳ, xuất file | Không tải lại không cần thiết, số liệu đúng |
| A11y | Tab, Shift+Tab, Escape, Reduced Motion | Focus rõ, tương tác được |
| Đa thiết bị | iPhone Safari/PWA, Android Chrome, desktop | Không bị che bởi keyboard/safe-area, không tràn ngang |
