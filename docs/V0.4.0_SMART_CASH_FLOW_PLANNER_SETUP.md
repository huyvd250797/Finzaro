# Finzaro V0.4.0 — Smart Cash Flow Planner

## SQL cần chạy

Vào Supabase → SQL Editor → New query, copy toàn bộ file:

`supabase/sql-editor/V0.4.0_smart_cash_flow_planner.sql`

và bấm **Run**.

Có thể kiểm tra read-only bằng:

`supabase/sql-editor/V0.4.0_smart_cash_flow_planner_verify.sql`

## Module mới

`/cash-flow` chuyển Forecast baseline thành kế hoạch tháng có thể lưu lại:

- Planned income
- Discretionary spending limit
- Savings reserve
- Extra debt payment
- Minimum cash buffer
- Safe to Spend
- Projected closing cash
- Baseline variance

Kế hoạch không tự tạo Transaction và không thay đổi Account Balance.

## Transaction Money Calculator

Ô số tiền trong giao dịch dùng `MoneyCalculatorInput`:

- hiển thị `1.000`, `100.000`, `1.000.000` theo locale `vi-VN`;
- keypad calculator mở ngay trong form;
- hỗ trợ `+`, `−`, `×`, `÷`, `=`;
- giá trị submit vẫn là canonical number để Transaction Core parse an toàn.

Ví dụ: `10.000 + 20.000 = 30.000`.
