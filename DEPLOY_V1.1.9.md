# Deploy Finzaro V1.1.9

No database migration is required for V1.1.9.

1. Replace the full source tree with V1.1.9.
2. Deploy with a clean Vercel build cache once.
3. Confirm the app badge shows V1.1.9.
4. Open a new Expense/Income transaction and verify the category grid shows 3 blocks per row on phone and 4 on wider screens.
5. Hold a category block, drag it to a new position, release, close/reopen the form and confirm the order persists.
6. Verify Category Management no longer shows the unexplained white shortcut button.
7. Save a normal income/expense transaction and compare the pending duration with V1.1.8.
