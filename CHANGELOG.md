# Finzaro Changelog

## V0.0.12 — Credit Card Manager
- Added `credit_cards`, `credit_card_statements`, `credit_card_payments` with RLS and validation.
- Added credit limit, current balance, utilization, statement/due dates, minimum payment and repayment history.
- Added optional ledger-linked credit-card payments and account-archive guards.
- Added atomic `update_financial_transaction_v012` for editing Income/Expense while preserving transaction IDs.
- Added visible instant Category edit workflow.
- Standardized mobile tabbar typography/icon sizing and expanded More module sheet.
- Added Finzaro launch splash + route loading fallback.
- Refined finance visual system, cards, fields, buttons and typography.
- Updated current version to `V0.0.12 · Credit Card Manager`.
